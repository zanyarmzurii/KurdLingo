## 🚀 Installation

### Prerequisites
- Python 3.9+
- pip

### Setup

```bash
git clone https://github.com/YOUR_USERNAME/KurdLingo.git
cd KurdLingo
pip install -r requirements.txt
cp .env.example .env
python -m bot.main
