# 🌍 KurdLingo Bot (کوردلینگۆ)

بۆتێ ژیڕ یێ فێربوونا ۱۰ زمانێن جیهانی ب زمانێ **کوردی (بەهدینی)** د ناڤ تلگرامێ دا.

## 🚀 تایبەتمەندیێن سەرەکی
- فێربوونا ۱۰ زمانان (ئینگلیزی، عەرەبی، تورکی، و ...)
- پشکنین و هەڵبژارتنا ئاستان (Beginner, Intermediate, Advanced)
- سیستەمێ کویز و تاقیکرنێن کارلێککار
- سیستەمێ ڤەخوێندنا هەڤالان (Referral System)
- ئاگەهدارکرنا ئادمنی بۆ دروستکرنا بڕوانامەیان
